# AI resumption guide — GitHub Profile

1. Read existing authoritative documents: README.md.
2. Read PROJECT_CONTEXT.md, LATEST_HANDOFF.md and PROJECT_PROGRESS.md in this folder.
3. Before changing assumptions read DECISION_LOG.md, DISCUSSION_SUMMARIES.md, REQUIREMENTS_AND_PREFERENCES.md, IDEAS_AND_REQUESTS.md and RESEARCH_AND_SOURCES.md.
4. Verify current branch, history, issues, PRs and test outcomes instead of trusting a stale summary.
5. At meaningful milestones, carry out SESSION_CLOSEOUT_CHECKLIST.md and update only relevant records without burdening the owner with many confirmations.
6. Keep original project files where they belong. Only claim uploads, images and outputs are saved after confirming real bytes in approved storage. Keep large/private assets encrypted or separately protected.
7. Keep superseded decisions with explanations. Do not invent past discussion text or silently override project instructions.

Project orientation: Public GitHub profile repository. Save only public-safe technical decisions and references; no raw chats, private material or personal archives.
